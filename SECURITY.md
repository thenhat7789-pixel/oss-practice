# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please do NOT report security vulnerabilities through public issues.

Use one of these private channels:
- GitHub: open the Security tab and click "Report a vulnerability"
- Email: thenhat7789@gmail.com

Please include: a description, steps to reproduce, the affected version, and the impact.

## Our Response Process

- We acknowledge your report within 48 hours.
- We make an initial assessment (severity, affected versions) within 7 days.
- We fix and release a patch within 30-90 days depending on severity.
- After the fix is released, we publish a GitHub Security Advisory
  (with a CVE if applicable) and credit the reporter.
