📚 Bảng Tra Cứu Nhanh Lệnh Git Thông Dụng

git status
Kiểm tra trạng thái các tệp tin đã sửa, đã thêm hoặc chưa theo dõi.
git pull origin main
Cập nhật những thay đổi mới nhất từ kho chứa trên GitHub về máy.
git add .
Đưa toàn bộ các tệp tin đã chỉnh sửa vào khu vực hàng chờ (Staging).
git commit -m "nội dung"
Tạo bản snapshot lưu trữ trạng thái kèm dòng mô tả ngắn gọn.
git push origin main
Đẩy tất cả các commit từ máy cá nhân lên kho lưu trữ GitHub.
git log --oneline
Xem lịch sử các lần commit rút gọn chỉ trên 1 dòng đơn giản.
