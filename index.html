Nhấn vào từng bước dưới đây để xem câu lệnh và kết quả tương ứng trong Terminal:

Bước 1
git pull
Kéo code mới nhất từ GitHub về trước khi sửa
Bước 2
git add .
Đưa tất cả các thay đổi vào hàng chờ (Staging)
Bước 3
git commit
Tạo commit kèm dòng mô tả công việc
Bước 4
git push
Tải các thay đổi từ máy local lên GitHub
